# AI News Summarizer

An AI-powered web application that automatically summarizes news articles from URLs using Natural Language Processing (NLP).

---

## Features

- Summarize news articles directly from URLs
- AI-powered text summarization
- Sentiment analysis of articles
- Extracts article image, author, and publish date
- Responsive modern UI
- Fast and lightweight Flask application
